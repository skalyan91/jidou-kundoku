attested (see scripts/derive-onyomi-kana.py) use the 音韻地位 — Middle Chinese
phonological positions — supplied by the `qieyun` Python package.

The rime data it carries is the 廣韻 (Guangyun, 1008), a Song-dynasty rime
dictionary long in the public domain. The package is a dev-time dependency
only, like fontTools: nothing from it reaches the browser, only the derived
JSON index does.
